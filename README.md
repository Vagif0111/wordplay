# WordPlay – Oyunlarla İngilizce Kelime Öğren

## APK'yı GitHub'dan alma
1. GitHub'da yeni bir repo aç (ör. `wordplay`).
2. Bu klasörün içindekileri repoya yükle (`.github` klasörü dahil!). `main` dalına push et.
3. Repo → **Actions** sekmesi → "APK Olustur" çalışır (≈5-8 dk).
4. Bitince repo → **Releases** → `WordPlay.apk` dosyasını telefona indir ve kur
   (Ayarlar'dan "bilinmeyen kaynaklardan yüklemeye izin ver" gerekir).

Elle başlatmak için: Actions → APK Olustur → Run workflow.

## Uygulamayı değiştirmek
Tüm uygulama `www/index.html` içinde. Değiştirip push edince yeni APK otomatik üretilir.
